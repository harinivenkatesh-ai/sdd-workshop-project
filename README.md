# Feature Scope Analyzer

A React + Vite web application built as part of the Spec Driven Development workshop assignment.

The application analyzes software project ideas, detects technical capability keywords, estimates implementation complexity, and generates MVP-focused recommendations.

---

## Features

- Freeform project idea analysis
- Technical keyword detection
- Alias-aware keyword matching
- Complexity classification:
  - Low
  - Medium
  - High
- Dynamic MVP recommendations
- Empty input validation
- Automated testing with Vitest
- React-based responsive UI

---

## Example Inputs

- AI blockchain realtime chat payment platform
- livestream classroom application
- crypto donation tracker
- banking platform with instant messaging
- chatbot ecommerce assistant
- decentralized voting application
